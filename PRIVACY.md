# Ciwaan Privacy Policy

**Effective date: August 27, 2026**

Ciwaan is a digital-addressing and navigation service. This policy explains what the current MVP processes, why it processes it, and the choices available to users.

## 1. No account required
Ciwaan does not require an account, password, email address, phone number, or user profile to create, find, or navigate to a Ciwaan.

## 2. Location information
Ciwaan requests device location permission only when a feature needs it. Creating a Ciwaan can use the current GPS location to place the map. Guide Me uses the device's live location while navigation is active so the app can display your position, route, distance, progress, and arrival.

If you deny permission, features that require your current position will not work, but the app can still be used for local saved-address features.

## 3. Address information
In the current MVP, created Ciwaans are stored locally on the user's browser/device. A local record contains the Ciwaan code, place name, selected latitude and longitude, exact/general precision choice, and creation timestamp. No account or cloud database is required by the current MVP.

A Ciwaan shared through its code or link is intended to disclose the associated location to the recipient. Do not create an exact Ciwaan for a private location unless you intend to share its precise location.

## 4. General location
The general-location option is intended to represent a less precise location choice than an exact Ciwaan. Users should still avoid sharing sensitive locations when they do not intend to disclose them.

## 5. Live navigation
Ciwaan uses live device location while Guide Me is active. The current MVP does not intentionally create a permanent movement history. Location coordinates are used in the browser to update the user's position and to request walking-route calculations.

## 6. Map and routing services
The current MVP uses MapLibre GL JS to render maps, OpenStreetMap map tiles for map imagery, and a public Valhalla OpenStreetMap routing service for pedestrian route calculations. Route requests necessarily contain geographic coordinates needed to calculate the route. The third-party providers' own terms, privacy policies, logging, and rate limits may apply.

The public routing service is intended for fair-use development/testing. A production deployment should use dedicated infrastructure or a provider appropriate for the expected traffic and privacy requirements.

## 7. Sharing
Ciwaan does not sell users' location data. A user can intentionally disclose a location by sharing a Ciwaan code or link. Once a location is shared, Ciwaan cannot control what a recipient does with the information.

## 8. Security
The current MVP does not require user accounts or a cloud database. Local browser/device storage is subject to the security of the device and browser. Users should protect devices that contain saved Ciwaans.

## 9. Children
Ciwaan is not directed to children under 13, and we do not knowingly collect personal information from children under 13.

## 10. Changes
This policy may be updated when the service, technology, or legal requirements change. Material changes will be reflected by updating the effective date.

## 11. Contact
Privacy requests should use the current contact method published with the Ciwaan service or its official distribution listing.

**Important:** This policy describes the current MVP's intended data practices. It is not a substitute for jurisdiction-specific legal advice. Before commercial launch, the operator should have the policy and processing arrangements reviewed by qualified counsel.
